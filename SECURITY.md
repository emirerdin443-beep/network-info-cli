# Security Policy

## Supported Versions

This project is primarily intended for educational and diagnostic use.

Security fixes will generally be applied to the latest version.

| Version | Supported |
| --- | --- |
| Latest | Yes |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than opening a public issue.

Please include:

- A clear description of the issue
- The affected file or feature
- Steps to reproduce the issue
- Expected and actual behavior
- Relevant logs or technical details

Please avoid publicly disclosing the vulnerability before it has been reviewed.

## Scope

Network information may contain sensitive details such as IP addresses, hostnames, interface names, and DNS configuration. Review output before sharing it publicly.
